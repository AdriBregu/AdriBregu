# Adri Bregu — Academic & Research Website

A static GitHub Pages website focused on academic research, climate econometrics, teaching, education, and research projects.

## Before publishing

1. Replace `YOUR_USERNAME` in `index.html` with your GitHub username.
2. Add your own `cv.pdf` to the repository root.
3. Optionally add links for Google Scholar, ORCID, ResearchGate, etc.
4. Review the contact details before publishing.

## GitHub Pages

Create a repository named:

`YOUR_USERNAME.github.io`

Upload the files to the root of the `main` branch, then go to:

Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`

GitHub Pages will publish the site at:

`https://YOUR_USERNAME.github.io`
